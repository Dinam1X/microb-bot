# ПАО МикРоб + Банк микробиксов хехе (@MicrobRobBot)

Один Telegram-бот на `python-telegram-bot` (async, v20+), объединяющий обе
части из ТЗ в одном процессе с одной базой `data/db.json` — так баланс,
акции и вклад гарантированно синхронны (не нужен общий диск между двумя
деплоями).

- Акции, задания, голосования, дивиденды, дашборд компании — кнопка «💰 Банк»
  открывает банковскую часть (счёт, вклад под 10% годовых, переводы, история)
  в том же чате.
- Регистрация (имя → роль) при `/start`. Первые два зарегистрированных
  получают по 500 акций (всего 1000).

## Установка

Требуется Python 3.10–3.12 (на 3.13+ не для всех пакетов есть готовые wheel).

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и впишите токен бота (получить у
[@BotFather](https://t.me/BotFather)):

```
BOT_TOKEN=...
```

## Запуск

```bash
python -m bot.main
```

При первом запуске `data/db.json` создаётся автоматически.

## Структура

```
bot/
  main.py          один Application, регистрирует все хендлеры + планировщик
  company.py        дашборд, акции, задания, голосования, акционеры, профиль, регистрация
  bank.py           счёт, вклад, перевод, история
  keyboards_company.py / keyboards_bank.py
  scheduler.py       дивиденды, пересчёт цены, просрочки, капитализация процентов
  charts.py          график цены акции (matplotlib)
common/
  db.py              атомарная JSON-база (file lock)
  models.py          формулы (проценты, цена акции, пороги голосования)
  money.py           форматирование сумм
  notify.py          безопасная отправка уведомлений
data/db.json         создаётся автоматически
```

## Игровые правила (из settings в db.json)

- Стартовая цена акции — 100 ₽, стартовый баланс — 10 000 ₽.
- Вклад — 10% годовых, капитализация ежедневно, кредиты запрещены.
- Дивиденды — 30% кассы компании, раз в день, пропорционально пакету акций.
- Порог выполнения/отклонения задания голосованием — >50% акций.
- Порог эмиссии акций / изменения настроек — ≥51% акций.
- Просрочка задания — цена акции падает (`k_penalty`), следующая прибыль ×
  `penalty_multiplier` до `penalty_reset_tasks` подряд выполненных заданий.

Коэффициенты редактируются через `data/db.json` → `settings`, либо
голосованием «Изменение настроек» в боте.

## Что не реализовано

Из раздела «Дополнения» ТЗ не реализованы необязательные расширения:
достижения/бейджи, экспорт отчётов, «IPO для друзей», реферальная кнопка с
бонусом за приглашение.
